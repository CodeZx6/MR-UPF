# Enhancing urban flow prediction via mutual reinforcement with multi-scale regional information

[![DOI](https://img.shields.io/badge/DOI-10.1016%2Fj.neunet.2024.106900-blue)](https://doi.org/10.1016/j.neunet.2024.106900)
[![Project page](https://img.shields.io/badge/project-page-blue)](https://codezx6.github.io/papers/mr-ufp.html)

Official implementation of **MR-UFP** — *Enhancing urban flow prediction via mutual reinforcement with multi-scale regional information* (Neural Networks 2025). MR-UFP improves urban flow prediction on small or noisy data by pre-training with spatial-temporal masking and contrastive learning, then jointly training the predictor with a multi-scale region-classification task that mutually reinforces spatial features.

📄 Paper: https://doi.org/10.1016/j.neunet.2024.106900 · 🌐 Project page with abstract, FAQ and BibTeX: https://codezx6.github.io/papers/mr-ufp.html · 👤 Author: [Xu Zhang](https://codezx6.github.io)


A deep learning framework for spatio-temporal prediction incorporating multi-scale semantic representations and heterogeneous feature fusion mechanisms.

## Architecture

The framework consists of hierarchical encoding modules with cross-modal attention mechanisms and adaptive feature aggregation strategies.
